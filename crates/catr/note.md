# On the Catwalk
## How cat Works cat
``cat``命令功能为 ： 能够将多个文件合并为一个文件
例如 ``cat a b c > all`` 表示将文件a, b, c按照输入顺序读取所有行，并将结构添加到all文档中
``cat``的常用选项
``-b`` 对非空白输出行编号，从1开始
``-n`` 对所有输出行编号，从1开始
``-T`` 显示非打印字符并将制表符(Tab)显示为^I
``-v`` 显示非打印字符并用^ 或者M-标记
``-t`` 等价于-vT
``cat`` 也可以从标准输入(当空参数或者用'-'的文件)读取数据并从标准输出进行输出

``cat``遇到不存在或者无法打开的文件，需要想stderr输出错误信息，然后处理下一个文件 如果同时存在-b, -n两个参数

## Getting Started
### Creating a Library Crate
将src/main.rs中的重要部分移动到src/lib.rs中名为run的函数
默认情况下，模块中的所有变量和函数都是私有的
仅对同模块内的其他代码可见
并且父亲模块无法看到子模块的私有内容
子模块可以直接使用夫模块的所有内容
### Defining the Parameters
由于命令行参数之间是有明显的联系，我们使用Config来表示这些参数
